# 🌐 Personal Portfolio Website

A personal portfolio website built using **HTML and CSS** to showcase my skills, projects, interests, and background.

## 🚀 Features

* Clean and responsive portfolio design
* Home/landing page
* About Me section
* Skills section
* Projects section
* Smooth hover and transition effects
* Multi-page navigation

## 🛠️ Technologies Used

* **HTML5** – Used to structure the website
* **CSS3** – Used for styling, layout, animations, and responsiveness
